# ADR 0016: Canonical Flow Compilation And Authoring

## Status

Superseded on 2026-07-29 by [ADR 0020](0020-creator-first-application-graph.md).

## Disposition

This ADR described the deleted `FlowSourceReader`, `FlowCompiler`, and `CompiledFlow` model. Current
projects use the flat `railix.project.json` contract and the single generated-application path in
ADR 0020. The obsolete types, evidence links, and deferred item numbering are not retained.
