# ADR 0019: Runtime Settings And Secrets

## Status

Superseded on 2026-07-30 by [ADR 0020](0020-creator-first-application-graph.md) and the accepted
[roadmap](../ROADMAP.md).

## Disposition

The removed pre-Creator graph implemented the settings and secrets design recorded here. Current
Railix does not support runtime settings or secrets. Their future contract belongs to a dedicated
roadmap slice; no deleted configuration, provider, or zeroization API remains supported.
