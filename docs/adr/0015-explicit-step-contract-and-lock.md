# ADR 0015: Explicit Step Contract And Lock

## Status

Superseded on 2026-07-29 by [ADR 0020](0020-creator-first-application-graph.md).

## Disposition

This ADR described the removed pre-Creator graph, `StepLock`, and package model. The current flat
Step contract, explicit catalog registration, implementation addresses, and dependency ownership
are defined by the [system model](../specs/system-model.md), with rationale in ADR 0020
and earlier proof in [verification history](../verification.md).

No current source or contributor workflow should use the deleted symbols from this decision.
