Effects use name.mml; music groups use music/group/name.mml.

Use name:, tempo:, then parallel lines: sine .3 .01 .1 | t120 o4 l8 /: c e g e :/4. Notes a-g, r rests, [ceg] chords, octave o, length l, and bounded repeats :/n are supported. Optional before |: decay=.18 sustain=.2 cutoff=1800 controls decay seconds, held level and filter Hz. detune=7 drive=2 pan=-.3 echo=.2 adds oscillator spread (cents, 0-30), saturation (0-8), stereo position (-1 to 1) and beat-synced echoes (0-.5).
